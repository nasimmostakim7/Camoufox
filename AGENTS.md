# AGENTS.md

Repository-specific knowledge for agents working in this fork
(`mostakimnasim3/camoufox`, upstream `daijro/camoufox`).

## What this repo is

Camoufox is an anti-detect fork of Firefox for scraping/automation. This tree is
**not** the Firefox source — it is a build system that downloads upstream Firefox,
applies `patches/` + copies `additions/`, and produces a hardened browser.
Fingerprint spoofing happens at the **C++/Juggler level**, not via injected JS,
so page-side inspection cannot see it.

`camoufox-<version>-<release>/` is generated by the build. Never edit it for
lasting changes; persist changes as patches instead.

## Two independent halves

| Half | Path | Language | Purpose |
|------|------|----------|---------|
| Browser binary | `additions/`, `patches/`, `settings/` | C++, JS, patch files | The spoofing engine |
| Python client | `pythonlib/` | Python | Playwright-compatible launcher, fingerprint generation, CLI, GUI |

They connect at runtime through the **Juggler** protocol (Firefox's Playwright
automation protocol) and the **`CAMOU_CONFIG`** env var (JSON read once at
process start by `additions/camoucfg/MaskConfig.hpp`).

## Pipeline (build → release → run)

1. `Makefile` sources `upstream.sh` (`version`, `release`) and exports them everywhere.
2. `make dir` = `setup` (aria2c fetch → extract → `copy-additions.sh`) → `scripts/patch.py`
   → writes `mozconfig` → touches `_READY`. Requires host Python ≥ 3.11 (`tomllib`).
3. `make build` / `make bootstrap` run `mach`.
4. `make package-linux|macos|windows arch=...` → `scripts/package.py` → release zips
   (`camoufox-{version}-{build}-{os}.{arch}.zip`).
5. `pythonlib/camoufox/pkgman.py` syncs/fetches those zips from GitHub releases
   (`pythonlib/camoufox/repos.yml` lists sources).
6. `pythonlib/camoufox/utils.py::launch_options()` builds the Playwright launch dict
   + `CAMOU_CONFIG`, then `playwright.firefox.launch()` starts the binary.

## Key entry points

- `pythonlib/camoufox/sync_api.py` — `Camoufox` context manager, `NewBrowser()`, `NewContext()`.
- `pythonlib/camoufox/async_api.py` — async equivalents.
- `pythonlib/camoufox/utils.py` — `launch_options()` (the big option surface) + helpers.
- `pythonlib/camoufox/fingerprints.py` — `generate_context_fingerprint()` (BrowserForge + presets).
- `pythonlib/camoufox/server.py` — `launch_server()`, websocket Playwright server.
- `pythonlib/camoufox/__main__.py` — the `camoufox` CLI (fetch/set/sync/list/remove/test/server/gui/version/path/active).
- `pythonlib/camoufox/gui/` — Qt/QML manager UI (`backend.py` + `qml/main.qml`).
- `additions/camoucfg/MaskConfig.hpp` — reads `CAMOU_CONFIG_1..N`, falls back to `CAMOU_CONFIG`.
- `additions/camoucfg/MouseTrajectories.hpp` — humanized cursor algorithm.
- `additions/juggler/` — patched Juggler; `content/main.js` + `protocol/PageHandler.js` are the core.

## Constraints

- Cross-compilation only: Windows/macOS binaries are built **from Linux**.
- 40 patches in `patches/` (+ `playwright/`, `librewolf/`, `ghostery/` subdirs).
  Order matters — see `patches/patch-dependencies.md`. `config.patch` provides
  `camoucfg`, which many other patches include.
- Do not hand-edit `.patch` files; use `make edits` (`scripts/developer.py`) or the
  low-level `make patch|unpatch|workspace|revert|diff` targets.
- `ccache` is enabled: cold build ~40 min, incremental ~5 min.
- License is **MPL-2.0**; keep the license header/source obligations intact when
  redistributing modified files. Keep the upstream fork relationship visible.

## Fork feature: proxy rotation

This fork adds per-session exit-IP rotation (`pythonlib/camoufox/proxy.py`).
Keep it in the additive, browser-free style of the rest of `pythonlib/`.

Two rotation points, deliberately different:

- `Camoufox`/`AsyncCamoufox(proxy_rotator=...)` — one exit IP per **browser**.
- `NewContext`/`AsyncNewContext(proxy_rotator=...)` — one exit IP per **context**,
  which is the "new IP per visit" case: reuse the browser, open a context per
  visit, get a new fingerprint there too.

Two modes: `gateway` (one rotating endpoint; a `{session}` token in the URL is
substituted per session) and `file` (a text list, one proxy per session).

Invariants worth not breaking:

- Nothing is persisted that identifies a proxy beyond `host:port` plus a short
  username hash. Passwords must never reach the state file or the logs.
- `acquire_session()` is serialised by `self._lock`; cursor advancement and the
  assignment counter must stay inside it. Rotation order is observable only via
  `ProxySession.sequence` — concurrent callers return out of order, so tests must
  sort by it rather than assume the returned list is positional.
- No silent direct fallback: an unusable pool raises instead of leaking the host
  IP under a foreign fingerprint. `allow_direct_fallback=True` is the opt-out.
- A repeated exit IP is rejected, not accepted, when verification runs.

Tests: `pythonlib/tests/test_proxy_rotation.py` (offline, no browser — a fake
browser object stands in). Keep it that way; a suite that dials real proxies is
slow and flaky.

CLI: `camoufox proxy check|status|reset`.
